工具

V 选择 / 变换
H / 空格 平移画布
R 矩形　E 椭圆　L 直线
A 箭头　P 折线　B 画笔
T 文本　I 插入图片
滚轮 缩放　0 适应画布

操作技巧

Shift + 点击 = 多选 / 加选
Shift + 绘制 = 正方形 / 正圆 / 角度吸附
Alt + 绘制 = 从中心开始
Shift + 缩放 = 等比例；旋转时吸附 15°
框选空白区域可批量选择；双击文本可编辑

编辑

Ctrl+Z 撤销 / Ctrl+Shift+Z 重做
Ctrl+C/X/V 复制 / 剪切 / 粘贴
Ctrl+D 再制　Delete 删除
Ctrl+A 全选　Esc 取消选择
Ctrl+G 组合 / Ctrl+Shift+G 取消组合
方向键 微移 1px（Shift ×10）
Ctrl+S 保存 · Ctrl+O 打开

文件

可打开任意 SVG 文件、拖放 SVG / 图片到画布；支持导出 SVG、PNG 与直接编辑源码。编辑内容会自动暂存到浏览器，刷新后自动恢复。

说明：PNG 导出为 2 倍分辨率。若 SVG 内引用了跨域图片，浏览器可能拒绝导出 PNG，此时请改用 SVG 导出。

Ctrl+Enter 或点击空白处保存 · Esc 取消
